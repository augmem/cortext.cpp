# Model card: AIST-87M-DH (standing-directive head)

## What it is

A small learned classifier over frozen AIST-87M features. It decides whether a stored signal states a
**lasting directive or preference**, that is, something the user wants applied to future answers. Examples:
"Always cite the version", "From now on reply in French", "I prefer aisle seats", "Under no circumstances
use emoji". When it says yes, the signal joins the bounded standing set (`standing_signals`). It is meant to
replace the English marker rule `IsStandingDirective` in `src/operations/standing_memory_internal.cpp`.

## Training data

- **Source.** All training data is synthetic. It was generated by `gen.py` through the CPA proxy, using only
  `gabe-codex-0/gpt-6.1-sol` and `gabe-codex-1/gpt-6.1-sol` with reasoning `low` and the `CPA_ROTATE` load
  balance. No Claude or Anthropic models were used, and no `ryan-codex` pools.
- **Prompts.** `spec.py` holds the system prompt, the user template and the label rules. It also holds 22
  categories with 74 templates and 40 topic areas, across three rounds (README, Data).
- **Size.** 3,499 generation cells (12 messages requested per cell) returned 52,320 messages. After script
  checks, exact dedupe and near-dup removal, 52,261 rows remain: train 34,505, val 6,358, test 11,398.
- **Languages.** en, es, fr, de, pt, ja, zh, ko, hi, ar, with about 5,200 rows each. 37% of rows are
  positive.
- **Hard negatives.** These are one-task instructions that use marker words ("make sure this email…", "wait
  here until…"), idioms ("never mind", "always sunny"), questions about preferences, reported speech, habit
  and fact narration, assistant-voice advice, temporary or hypothetical preferences, and small talk.
- **Splits.** Splits are by template and topic, never by random row:
  - 21 of the 74 templates appear only in test.
  - 8 of the 40 topics appear only in test, and 4 others appear only in validation.
  - A text found in more than one split is kept in the held-out split only.
  - Any train row with char-3–5-gram TF-IDF cosine ≥ 0.9 to a held-out row is removed.
- **Stream formatting.** 60% of rows get a synthetic timestamp and/or speaker prefix of the kind memory streams
  use. The prefix is independent of the label.

### Benchmarks excluded from training

None of these were used for training, threshold choice or model selection: LongMemEval, LoCoMo, BEAM,
MemLens, DolphinBench. They are used only in the evaluation reported in the README, which covers stream flag
counts, judged disagreements and BEAM gold recall.

### Public datasets

No public dataset was used for training.

- **OpenAssistant oasst1.** It was downloaded but is **unused**. Source: `OpenAssistant/oasst1` on Hugging Face,

## Intended use and limits

- **Use.** The head is a write-time membership test for the standing set. It is not a general intent
  classifier.
- **Non-Latin scripts.** The engine's AIST tokenizer maps every byte ≥ 0x80 to `[UNK]`. For Japanese,
  Chinese, Korean, Hindi and Arabic, the encoder therefore sees only `[UNK]` runs, ASCII and spacing, so any
  head on the current encoder is close to chance there. Two Japanese sentences with unrelated meaning embed at
  cosine 1.0000. The README quantifies this with a counterfactual Unicode tokenizer.
- **Synthetic data.** Labels come from an LLM generator under a written definition. The README reports a
  judge spot-check on real streams.
- **Speaker.** The head sees only the signal's own text, so a speaker prefix ("assistant:") is a weak cue.
  Assistant-voice advice is the costliest false-positive class.
