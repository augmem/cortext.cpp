# Plan: Database Schema v2 (Clean Slate)

## Overview

This plan **replaces** the v1 schema (Migration 0) with v2 schema as documented in `docs/diagrams/database-v2.md`. This is a **clean slate breaking change** - existing databases are incompatible and must be recreated.

**New Hierarchy: EPISODES -> MEMORIES -> SIGNALS -> (EMBEDDINGS, BLOBS)**

## Key Changes Summary

| Aspect | v1 (Old) | v2 (New) |
|--------|----------|----------|
| Hierarchy | EMBEDDINGS at top | EPISODES -> MEMORIES -> SIGNALS -> EMBEDDINGS |
| Memory metadata | Split across 5 tables | Unified MEMORIES table |
| Signal metrics | Separate signal_metrics table | Inline on SIGNALS |
| Working memory | working_memory_slots table | MEMORIES.kind = 'WORKING' |
| Graph/associations | graph_nodes + graph_edges | Single ASSOCIATIONS table |
| State tables | processor_state + 4 blender tables | Single STATE table |
| Sliding windows | 5 separate tables | Computed as views |
| Blob storage | objstore | Renamed to BLOBS |

## Constraints

1. **Clean slate**: No data migration - existing databases must be deleted
2. **sqlite-vec**: Minimal auxiliary columns, most metadata in MEMORIES
3. **Migration 0**: Replaced entirely with new schema
4. **No backwards compatibility**: Old databases will not work

### TODO 2.3: Create Views (Computed Windows)
```sql
-- recent_context view
CREATE VIEW IF NOT EXISTS recent_context AS
SELECT s.embedding_id, e.embedding, s.timestamp
FROM signals s
JOIN embeddings e ON s.embedding_id = e.embedding_id
ORDER BY s.timestamp DESC
LIMIT 64

-- recent_scores view
CREATE VIEW IF NOT EXISTS recent_scores AS
SELECT signal_id, score, timestamp
FROM signals
WHERE score IS NOT NULL
ORDER BY timestamp DESC
LIMIT 100

-- recent_ids view
CREATE VIEW IF NOT EXISTS recent_ids AS
SELECT DISTINCT embedding_id, timestamp
FROM signals
ORDER BY timestamp DESC
LIMIT 1024

-- recent_retrievals view
CREATE VIEW IF NOT EXISTS recent_retrievals AS
SELECT memory_id, last_access as timestamp
FROM memories
WHERE last_access IS NOT NULL
ORDER BY last_access DESC
LIMIT 128
```
